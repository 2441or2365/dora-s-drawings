# 🎨 Рисунки Даши в Paint

Добро пожаловать в официальный репозиторий цифрового искусства, созданного Дашей в программе **Microsoft Paint**! Здесь собрана уникальная коллекция шедевров, нарисованных мышкой, с душой и без права на ошибку (ладно, иногда с `Ctrl + Z`).

## 🖼️ О проекте

Этот репозиторий создан для бережного хранения, каталогизации и демонстрации работ Даши. Каждый пиксель здесь — результат вдохновения, смелых цветовых решений и классических инструментов (кисть, заливка, баллончик и кривые линии).

## 🛠️ Инструменты художника

* **ПО:** Microsoft Paint (классический)
* **Холст:** Белый прямоугольник по умолчанию
* **Инструмент ввода:** Обычная компьютерная мышь
* **Палитра:** Стандартный набор цветов сверху экрана
